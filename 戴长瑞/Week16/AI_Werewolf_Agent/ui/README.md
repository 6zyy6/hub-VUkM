# AI Werewolf Streamlit UI

基于 Web 的狼人杀可视化界面，实时展示 AI 对战过程。

## 运行方式

```bash
cd AI_Werewolf_Agent
streamlit run ui/app.py
```

## 功能

### 实时显示
- 游戏阶段（夜晚/白天）
- 当前天数
- 存活玩家数量
- 狼人数量

### 玩家状态卡片
- 玩家名称
- 身份（狼人/村民/预言家/女巫）
- 存活状态
- 狼人用红色标记

### 夜晚行动面板
- 狼人杀害目标
- 预言家查验结果
- 女巫用药情况
- 夜晚死亡名单

### 发言记录
- 实时滚动显示
- 玩家颜色区分（狼人/好人）

### 投票记录
- 投票统计柱状图
- 详细投票记录

### 控制面板
- 开始新游戏
- 继续下一步（单步执行）
- 自动运行（快速完成）
- 重置游戏

## 角色说明

| 角色 | 图标 | 数量 | 能力 |
|------|------|------|------|
| 狼人 | 🐺 | 2 | 夜晚杀害一名玩家 |
| 预言家 | 👁️ | 1 | 夜晚查验一名玩家身份 |
| 女巫 | 🧪 | 1 | 解药救人、毒药毒人 |
| 村民 | 😊 | 2 | 无特殊能力，分析找出狼人 |

## 胜利条件

- **好人胜利**：所有狼人被放逐
- **狼人胜利**：狼人数量 >= 好人数量
