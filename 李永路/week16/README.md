# AI 狼人杀 - 多智能体协作与博弈系统

## 项目简介

基于多 Agent 协作框架，构建一个能够自主完成信息不对称博弈的狼人杀 Agent Team 系统。每个 Agent 根据其扮演角色（狼人、预言家、女巫等）拥有独立的目标、策略与行动空间，在严格信息隔离的约束下进行推理、发言与决策。

## 核心特性

- ✅ **多角色 Agent 系统**：支持狼人、村民、预言家、女巫、猎人、守卫等多种角色
- ✅ **信息隔离机制**：每个 Agent 只能获取其角色允许的信息
- ✅ **完整对局引擎**：自动驱动回合流转与胜负裁决
- ✅ **结构化日志**：全程可观测，支持复盘分析
- ✅ **灵活配置**：支持多种玩家规模和角色分布

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行游戏

#### 使用简化配置（6人局）
```bash
python main.py --config simple_6
```

#### 使用标准配置（12人局）
```bash
python main.py --config standard_12
```

#### 使用快速测试配置（4人局）
```bash
python main.py --config quick_4
```

#### 自定义参数
```bash
python main.py --config simple_6 --max-rounds 15 --log-dir my_logs
```

## 角色说明

| 角色 | 阵营 | 技能 |
|------|------|------|
| 狼人 (Werewolf) | 狼人阵营 | 夜间击杀一名玩家 |
| 村民 (Villager) | 好人阵营 | 无特殊技能，通过推理找出狼人 |
| 预言家 (Seer) | 好人阵营 | 每晚查验一名玩家的身份 |
| 女巫 (Witch) | 好人阵营 | 一瓶解药（救人）+ 一瓶毒药（杀人） |
| 猎人 (Hunter) | 好人阵营 | 死亡时可以带走一名玩家 |
| 守卫 (Guard) | 好人阵营 | 每晚守护一名玩家（不能连续两晚守护同一人） |

## 游戏流程

1. **夜间阶段**
   - 守卫选择守护目标
   - 狼人团队讨论并选择击杀目标
   - 女巫决定是否使用解药或毒药
   - 预言家查验一名玩家身份

2. **白天阶段**
   - 公布昨晚死亡情况
   - 所有存活玩家依次发言
   - 投票淘汰一名玩家
   - 检查游戏是否结束

3. **胜利条件**
   - 狼人胜利：狼人数量 >= 好人数量
   - 好人胜利：所有狼人被淘汰

## 输出示例

游戏运行时会实时显示：
- 每轮的行动日志
- 玩家的发言内容
- 投票结果
- 游戏最终报告

日志文件保存在 `logs/` 目录下，包含：
- `.log` 文件：详细的游戏过程日志
- `.json` 文件：结构化的游戏报告

## 进阶功能（可扩展）

### ① 通用 Agent - 自演化系统
探索"读懂自己修改自己运行自己"的自演化系统，从「通用 Agent」演化为「狼人杀多角色 Agent」。

### ② 评测+复盘
构建结果评测、过程评测等多维可量化评测体系，基于此完成任意游戏的复盘归因，并产出不同版本、不同模型 Agent 同台竞技的 Leaderboard。

### ③ 自进化 Agent
实现"对局分析→优化→再对局"自进化循环，使各角色 Agent 在多局迭代中持续提升胜率。
