# 第十三周作业1答案

## 题目

阅读 `2412-DeepSeek-V3.pdf`，总结 DeepSeek-V3 相比 DeepSeek-V2 的改进。

## DeepSeek-V3 相比 DeepSeek-V2 的主要改进

### 1. 在保留 V2 高效架构的基础上，新增了两项核心创新

DeepSeek-V3 并不是推翻 V2 重做，而是在 V2 已经验证有效的高效架构上继续增强。

- 延续了 V2 中已经验证过的 `MLA (Multi-head Latent Attention)`，继续降低 KV Cache 和推理成本。
- 延续了 `DeepSeekMoE` 架构，继续利用 MoE 提升参数规模与计算效率的平衡。
- 真正让 V3 相比 V2 拉开差距的，是两项新的训练与路由改进：
  - `auxiliary-loss-free load balancing`（无辅助损失负载均衡）
  - `Multi-Token Prediction`（多 Token 预测，MTP）

也就是说，V2 主要解决“高效架构”问题，V3 则进一步解决“训练更稳、专家负载更均衡、推理更快、效果更强”的问题。

### 2. 负载均衡策略升级：从有辅助损失，走向无辅助损失

MoE 模型里常见的问题是：如果没有负载均衡，部分专家会特别忙，另一些专家几乎不用，导致训练不稳定、资源利用差。

DeepSeek-V3 的一个重要改进是：

- 提出了 `auxiliary-loss-free` 的负载均衡策略。
- 相比传统依赖额外平衡损失项的方法，这种做法能减少因为“强行均衡”带来的性能损失。
- 结果是专家分配更自然，训练更稳定，同时尽量不牺牲模型主任务性能。

这点可以理解为：

- V2 已经把 MoE 做得很高效；
- V3 则进一步把 MoE 的“专家调度质量”做得更好。

### 3. 新增 MTP 训练目标：不只预测下一个 Token

V2 的核心仍然是传统自回归语言模型目标，即一次预测下一个 token。

V3 新增了 `Multi-Token Prediction (MTP)` 训练目标，主要改进有：

- 让模型在训练时学习更强的多步前瞻能力。
- 提升生成质量和整体性能，尤其对复杂任务更有帮助。
- MTP 模块还可以服务于 `speculative decoding`，从而带来推理加速潜力。

这一点说明 V3 相比 V2 的提升，不只是“模型更大”，而是训练目标本身更先进。

### 4. 训练效率进一步提升：首次在超大规模模型上验证 FP8 训练可行

论文和官方说明都强调，DeepSeek-V3 在预训练效率上做了很大优化：

- 设计了 `FP8 mixed precision training framework`。
- 首次在超大规模 MoE 模型上验证了 FP8 训练的可行性与有效性。
- 通过算法、训练框架和硬件协同设计，显著缓解了跨节点 MoE 训练中的通信瓶颈。
- 接近实现了计算与通信的重叠，从而降低训练成本。

如果说 V2 更像是在架构层面证明“这样设计能省推理成本”，那么 V3 更进一步证明“这样的大模型还能以更低成本稳定训出来”。

### 5. 训练稳定性更强

V3 在工程层面的另一个明显提升是稳定性：

- 整个训练过程中没有出现不可恢复的 loss spike。
- 不需要回滚训练。
- 说明其大规模 MoE 训练流程已经比过去更成熟。

这属于 V2 到 V3 的重要工程化进步。因为超大规模 MoE 模型不仅要“训得动”，还要“稳定地训完”。

### 6. 训练数据规模和综合能力继续增强

DeepSeek-V3 的训练配置也明显更强：

- 在 `14.8T` 高质量、多样化 token 上预训练。
- 后续再经过 `SFT + RL` 阶段进一步对齐和增强能力。
- 官方结果显示，V3 整体上超过多数开源模型，并接近顶级闭源模型。

因此，相比 V2，V3 不只是局部优化，而是整体能力全面上探，尤其在：

- 数学
- 代码
- 推理
- 多语言
- 长上下文能力

这些方面更强。

### 7. 成本收益比更高

论文中给出的一个很重要指标是：

- DeepSeek-V3 完整训练只用了约 `2.788M H800 GPU hours`。
- 官方 README 中进一步拆分为预训练约 `2.664M H800 GPU hours`，后训练额外约 `0.1M GPU hours`。

这说明 V3 相比 V2 的升级方向非常明确：

- 不是单纯堆参数；
- 而是在“效果提升”的同时，继续追求训练和部署性价比。

### 8. 后训练阶段进一步吸收了 R1 系列的推理能力

官方说明里还提到，DeepSeek-V3 的后训练引入了从 `DeepSeek-R1` 系列蒸馏推理能力的方法：

- 将长链路推理中的 verification 与 reflection 模式蒸馏到标准 LLM 中。
- 让 V3 在保持通用助手风格的同时，增强 reasoning 表现。

这也是 V3 相比 V2.5/V2 体系更进一步的一点：它开始显式吸收 reasoning model 的优势。

## 一句话总结

DeepSeek-V2 的重点是：用 `MLA + DeepSeekMoE` 做出高效、低成本的 MoE 架构；
DeepSeek-V3 的重点是：在保留这套高效架构的基础上，再通过 `无辅助损失负载均衡 + MTP + FP8 大规模稳定训练 + 更强后训练`，把模型效果、训练稳定性和推理潜力同时往上推了一代。

## 简表总结

| 对比维度 | DeepSeek-V2 | DeepSeek-V3 |
| --- | --- | --- |
| 基础架构 | MLA + DeepSeekMoE | 延续 MLA + DeepSeekMoE |
| 负载均衡 | 传统思路为主 | 无辅助损失负载均衡 |
| 训练目标 | 主要是 next-token prediction | 新增 Multi-Token Prediction |
| 训练精度 | 高效训练，但未突出 FP8 大规模验证 | 明确验证 FP8 超大规模训练可行 |
| 训练稳定性 | 已较强 | 更稳定，无不可恢复 loss spike |
| 训练效率 | 强调高性价比 | 进一步优化通信与训练成本 |
| 推理潜力 | 依赖高效架构本身 | MTP 可用于 speculative decoding |
| 综合能力 | 强开源模型 | 更接近顶级闭源模型 |
