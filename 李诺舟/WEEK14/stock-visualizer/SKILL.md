# 股票波动可视化分析 Skill

当用户提出以下需求时使用本 skill：
- 分析某只股票最近的日波动和周波动
- 把周波动、日波动画在一张图里
- 根据波动大小和近期位置，判断更适合买入还是卖出

## 输入

- 股票代码，例如 `sh600519`
- 可选开始日期，例如 `2025-01-01`
- 可选结束日期，例如 `2025-05-14`

## 输出

- 一张同时包含日波动和周波动的图
- 一段简洁分析结论
- 一个偏保守的建议：
  - `适合买入`
  - `适合分批卖出`
  - `适合继续观察`

## 分析规则

1. 日波动 = `(high - low) / open`
2. 周波动 = `(high - low) / open`
3. 如果最近日波动显著放大，且价格接近区间高位，则偏向卖出或减仓。
4. 如果最近周波动回落、价格接近区间低位，且短期日波动未继续恶化，则偏向买入。
5. 如果周波动和日波动同时处于中位附近，没有明显极值，则继续观察。

