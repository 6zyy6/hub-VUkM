# DeepSeek-V3 相比 V2 的核心改进

- **参数规模大幅增长**：总参数量 236B → **671B**，激活参数 21B → **37B**。
- **训练数据更多**：从 8.1T tokens 增加到 **14.8T tokens**，并提高了数学、代码数据比例。
- **三大关键技术创新**：
  1. **无辅助损失的负载均衡**：移除传统辅助损失函数，改用动态偏置项实现专家负载均衡，提升模型性能。
  2. **多Token预测（MTP）**：训练时同时预测未来多个 token，提升推理质量，推理时仍保持单 token 预测效率。
  3. **FP8混合精度训练**：业界首个成功使用 FP8 训练的大模型，大幅降低显存和训练成本。
- **训练效率极高**：仅用 278.8 万 H800 GPU 小时，成本约 557.6 万美元，训练稳定无回滚。
- **性能卓越**：超越所有开源模型，与 GPT-4o 等顶尖闭源模型持平或更优。
