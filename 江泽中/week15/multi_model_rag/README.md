# 多模态RAG聊天机器人

一个基于Streamlit的多模态检索增强生成(RAG)系统，支持PDF文档的智能解析、向量存储和图文问答。

## ✨ 功能特性

- 📄 **文档上传**: 支持PDF、DOCX、TXT格式
- 🔍 **智能解析**: 使用MinerU解析PDF为Markdown+图片
- 💾 **向量存储**: BGE+CLIP双编码，Milvus向量数据库
- 💬 **图文问答**: 基于Qwen-VL的多模态问答
- 🖼️ **图片渲染**: 答案中自动嵌入相关图片
- 🔄 **异步处理**: Kafka消息队列，后台解析
