# AI狼人杀 - 多智能体协作与博弈系统

## 📖 项目简介

基于多Agent协作框架构建的狼人杀智能对战系统，每个Agent根据扮演角色（狼人、预言家、女巫等）拥有独立的目标、策略与行动空间，在严格信息隔离的约束下进行推理、发言与决策。

## ✨ 核心特性

- 🎭 **多角色扮演**：支持狼人、预言家、女巫、猎人、村民等经典角色
- 🤖 **智能Agent**：基于LLM的智能决策系统，实现自然语言推理与交互
- 🎮 **完整游戏引擎**：自动化驱动回合流转与胜负裁决
- 📝 **结构化日志**：全程可观测的游戏日志系统
- 📊 **评测体系**：多维度量化评估Agent表现
- 🔄 **自进化机制**：基于对局分析的持续优化循环
- 🌐 **前端界面**：Streamlit实现的观战UI
