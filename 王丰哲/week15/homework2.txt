1. MinerU 是什么？
MinerU 是一款开源的文档解析工具，能够把 PDF、图片和 Office 文档解析成 Markdown、JSON、图片裁剪结果以及版面可视化结果等结构化输出。它的优势在于不仅可以提取文本，还能够识别标题层级、阅读顺序、图片、表格、公式以及页面中的版面位置信息。因此，MinerU 特别适合用于 RAG 知识库前处理，因为它能够较完整地保留复杂文档的结构信息。

2. MinerU 论文主要讲了什么？
MinerU 的论文主要介绍了一套面向复杂文档的解析方案，核心目标是解决 PDF 中标题、段落、表格、公式、图片以及阅读顺序等结构识别问题。其中，MinerU2.5 提出了 coarse-to-fine 的两阶段解析思路：先利用低分辨率页面进行整体版面分析，再回到原图中裁剪局部区域做高精度识别。这样既保证了解析效果，又兼顾了计算效率。

3. MinerU 怎么使用？
MinerU 常见的使用方式有两种。第一种是命令行方式，例如使用 mineru -p input.pdf -o output_dir 对文档进行解析；第二种是启动 API 服务，例如使用 mineru-api --host 0.0.0.0 --port 8000。在本次实验中，实际采用的是命令行方式，并对课程 PDF 的前 3 页进行了测试。

4. pdfplumber 怎么使用？
pdfplumber 是一个轻量级的 Python PDF 解析库，主要适合快速提取原生 PDF 中的文字和表格。它的典型用法是先打开 PDF 文件，然后逐页提取文本和表格内容。相比 MinerU，pdfplumber 不需要额外下载模型，安装和运行都比较简单，因此更适合做基础的文本提取任务。

5. 本次解析结果如何？
本次实验使用同一个课程 PDF 的前 3 页作为测试对象。pdfplumber 的解析结果显示，输出文本字符数为 590，检测到 2 个表格对象，输出内容主要是线性文本，没有保留图片和版面结构。相比之下，MinerU 输出的 Markdown 字符数达到 924，生成了 12 个结构化 content item，还额外裁剪出了 2 张图片，并输出了 Markdown、content list JSON、middle JSON、layout PDF 和 span PDF 等多种结果。因此，MinerU 在结构化和版面信息保留方面表现更好。

6. 两者效果有什么差异？
pdfplumber 的优点在于轻量、快速、简单，适合处理原生文本型 PDF。它能够较方便地提取文字和部分表格，但对于图片、复杂版面、标题层级、扫描件和复杂课件的支持较弱。MinerU 的优点则是结构化能力更强，可以输出 Markdown、图片、边界框信息以及版面分析结果，更适合复杂文档解析和多模态 RAG 前处理。不过，MinerU 的缺点是依赖更多，首次运行通常需要下载模型，因此安装和启动成本比 pdfplumber 更高。
